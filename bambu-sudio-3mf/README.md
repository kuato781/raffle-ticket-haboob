# Bambu Studio Project

This directory contains the Bambu Studio project file(s) for the current Raffle Ticket Haboob parts.

Current project:

- `raffle_ticket_haboob_layout_drill_template_82mm_lipped_m25_v14.3mf`

The corresponding editable OpenSCAD and STL files live in [`../stl-scad/`](../stl-scad/).

Use the 3MF as a slicer starting point, but verify printer, material, layer height, wall count and other settings for your own machine before printing.
